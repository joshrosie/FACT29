# Reproducing Table 5: Baseline Comparisons

This document provides instructions on how to reproduce the results presented in **Table 5**, which compares different baseline methods on the **base** game against **GPT4o-mini**.

Each row in the table represents an experiment using a specific baseline method. To reproduce the results, a user needs to execute the **baselines.py** script with the appropriate method argument.

## Experiment Mapping

Each baseline method corresponds to a specific argument that should be passed when running the script:

| Method in Paper                      | Argument for `baselines.py` |
|--------------------------------------|----------------------------|
| **Random**                           | `random`                   |
| **Midline**                          | `midline`                  |
| **Previous-Proposal Proximity**      | `prev_prox`                |
| **Multi-Sample Consensus**           | `multi_sample_consensus`   |
| **Frequency-Restricted**             | `freq_restricted`          |
| **Two-Phase**                        | `two_phase`                |

## Valid Game Arguments

The `--game` argument should be set to one of the following valid game folders:
- `base`
- `base_rewritten`
- `game1`
- `game2`
- `game3`

## Running a Baseline Experiment

To reproduce the results for a specific baseline method and game setting, run the following command:

```bash
python baselines.py --game <game_folder> --method <method_name>
```

For example, to reproduce the results for **Multi-Sample Consensus** on `game1`, use:

```bash
python baselines.py --game game1 --method multi_sample_consensus
```

Each experiment will execute using the respective proposal generation method.

## Output Format

### Original Baseline Results:
The original results are stored under:
```bash
our_games_descriptions/<GAME>/output/baselines/<METHOD>
```
For example:
```bash
our_games_descriptions/base/output/baselines/multi_sample_consensus
```

### Reproduced Baseline Results:
The newly generated results will be saved separately under:
```bash
our_games_descriptions/<GAME>/output_reproduce/baselines/<METHOD>
```
This ensures that reproduced results remain distinct from the original logged outputs.

## Evaluation of Results

After running the baseline experiments, you need to process the output files to obtain the final performance scores. To do this, execute the evaluation script (`.ipynb`) on the generated output folders. Refer to the **Evaluation** section in the original README for detailed instructions on computing and comparing the performance metrics.
